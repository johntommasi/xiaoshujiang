## 一、先搞清楚一件事:预测下一词,远比你想象的难

很多人觉得”预测下一词”很简单,就是背诵、记忆嘛,背的语料多了自然就能接下去。

 **大错特错。** 

你试试这个:

> “小明比小红高,小红比小华高,所以\_\_\_”

下一个词是什么?

是”小明比小华高”对吧。但这不是记忆,是 **逻辑推理** 。

模型要能预测出这个,它必须理解”比”这个关系的传递性，记住前面句子里的实体关系然后把这些信息组合起来用自然语言表达出结论。 **这已经不是简单的模式匹配了,这是reasoning。** 

再来一个:

> “def fibonacci(n):  
> if n <= 1: return n return \_\_\_"

要预测这个空,模型得理解这是递归函数吧？得知道斐波那契数列的定义吧？得理解代码的语法和语义吧？ 然后才能生成正确的表达式 `fibonacci(n-1) + fibonacci(n-2)`

 **“预测下一个token”这个任务,实际上迫使模型学会了编程、数学、逻辑。** 

但问题来了——模型真的”学会”了吗?还是只是记住了训练数据里的这些模式?

## 二、一个关键:要预测,就必须压缩;要压缩,就必须理解

这个观点我第一次听到的时候,觉得很玄学。但仔细想想,确实有道理。假设你要预测这个序列的下一个数:

```text
2, 4, 6, 8, 10, ___
```

最笨的方法是把这个序列背下来。但如果序列有1000个数呢?1万个?

聪明的做法是 **发现规律** :“哦,这是等差数列,每次加2”。

这个规律只需要几个字节就能表示,但能生成无限长的序列。这就是 **压缩** 。

而发现规律的过程,某种意义上就是我们所说的 **智能** 。

LLM也是一样。

互联网上的文本是PB级别的,但GPT-3才175B参数(约700GB)。它不可能把所有文本都背下来—— **唯一的办法是提取规律、学习模式、建立某种内部表示。** 

这样一来,要预测下一个词,模型被迫要理解语法规则，掌握事实知识，学会逻辑推理。这也是我们评判一个模型好用不好用的三个基本的维度。

但这里有个问题: **压缩不等于理解。** 

ZIP压缩算法也能把文件压缩得很小,但你不会说ZIP”理解”了文件内容吧?所以LLM学到的,可能只是一种 **统计上的高级压缩** ,而不是真正的理解。

但这个争议到现在还没定论。

## 三、那些看起来的”涌现能力”,可能没那么神奇

2022年有篇很火的论文,说LLM有”涌现能力”——就是在模型规模达到某个临界点之前,完全不会做某个任务;达到之后,突然就会了。

比如算术能力小模型完全不会,大模型突然就会了；多步推理，在某个尺寸之后突然能做三段论推理；代码执行也是突然从不会变成会

这个曲线不是平滑的上升,而是像 **相变** 一样——就像水在99.9°C时还是液体,100°C突然就沸腾了。

 **听起来确实很玄学，很魔幻** 

但2023年斯坦福有篇论文提出质疑:这种”涌现”可能是假象,是因为我们用的评估指标太粗糙。

比如你用”答案完全正确”来评估,那就是0分或100分,中间没有过渡。但如果你用更细粒度的指标(比如”逻辑步骤正确程度”),你会发现能力是逐渐提升的,不是突变。就像你考试,60分以下不及格,60分以上及格。从59分到60分,看起来是”突然及格了”,但实际上能力提升是连续的,只是评估标准把它变成了离散的跳跃。

 **所以”涌现”可能根本不存在,只是我们的测量方式造成的错觉。** 

当然,这个解释也有问题。有些任务本身就是二元的,没有”部分可运行”这回事。所以真相可能在中间——有些能力确实是渐进的,有些可能真的存在某种相变。但至少这提醒我们: **不要轻易被”涌现”、”突破”这种词汇唬住了。** 

## 四、语言真的编码了智能吗?还是只是编码了模式?

有句话我觉得很好: **_人类用了几万年,把对世界的理解编码进了语言。_** 

你想想,“苹果”这个词,背后关联着:

-   视觉特征
-   味觉特征
-   分类知识
-   功能知识
-   物理知识

以至于你听到苹果这词后，你的脑海中会涌现出很多相关的信息。 **所以当模型学习预测文本时,它实际上在解码人类的知识体系。** 

这个观点很有启发性。但问题是—— **LLM真的”解码”了吗?还是只是学会了词语之间的统计相关性?** 

模型可能学到了:“苹果”和”红色”经常一起出现,“苹果”和”水果”经常一起出现。但它真的理解”红色”是什么吗?它没有视觉,没有触觉,没有味觉。它只是看到”红色”这个token在某些上下文中出现。就像一个天生失明的人,可以通过阅读学到”夕阳很美”,但他永远无法真正理解那种美。

 **LLM可能就是这样的”天生失明者”——它知道所有词语之间的关系,但不知道这些词语指向的真实世界是什么样的。** 

这也是为什么LLM会犯一些很低级的错误。它能解微分方程,但不知道”把水倒进杯子,杯子会发生什么”。因为它没有物理直觉,没有和真实世界互动的经验。

## 五、事实就是:我们其实不知道它为什么work

说了这么多理论,压缩啊、世界模型啊、元学习啊……听起来都很有道理。

但 **真相是:我们不知道LLM为什么能work。** 

你可以用各种理论去解释,每个理论都能解释一部分现象,但没有一个理论能完整地解释所有现象。就像量子力学早期,大家都知道公式能算出正确结果,但对于”为什么”、”背后的机制是什么”,争论了几十年。

LLM现在就是这个状态。

而且更诡异的是—— **有些能力,连训练者都不知道模型是怎么学会的。**  GPT-4突然能做一些GPT-3完全不会的事情,OpenAI的工程师也解释不清楚为什么。只能说”可能是规模大了,学到了什么新东西”。没什么能够真正科学的解释大模型下的原理到底是什么。现在我们确实在处在“赛博炼丹”的时期。

## 六、预训练只是第一步,后面还有很多操作

还有个容易被忽略的点: **我们用的ChatGPT、Claude,不只是预训练出来的。** 

预训练只是第一步。之后还有:

1.   **指令微调** :让模型学会遵循指令而不是续写文本
2.   **人类反馈强化学习** :让模型的回答符合人类偏好

这两步会显著改变模型的行为。有个很有意思的现象:同样的基座模型,经过不同的RLHF训练,表现出的能力可以差很多。有些会更保守，会拒绝回答敏感问题,有些会更激进,有些会更啰嗦,有些会更简洁。

 **所以我们观察到的”高级能力”,到底有多少是预训练学到的,多少是后续对齐带来的?** 

这个比例还不清楚。

也许预训练学到的只是”原材料”(语言统计规律、世界知识的模糊表示),而RLHF才是”加工过程”,把这些原材料雕刻成有用的形状。如果是这样,那”预测下一词就能涌现智能”这个说法就不太准确了——准确的说法应该是”预测下一词 + 指令微调 + 人类反馈强化学习,才能涌现出看起来像智能的行为”。

## 七、我们怎么定义”智能”?

说到这里,其实还是那个非常老套的问题: **什么是智能?** 

如果你定义”智能 = 能解决复杂问题”,那LLM确实表现出了智能。

如果你定义”智能 = 理解世界的本质”,那LLM可能离智能还很远。

如果你定义”智能 = 能灵活应对未知情况”,那LLM在某些情况下很智能,在某些情况下很愚蠢。

 **问题是,我们自己都没搞清楚”智能”到底是什么。** 

人类的智能,会不会也只是一种高级的模式匹配呢?我们的大脑预测下一秒会发生什么、预测别人会说什么、预测自己的行动会导致什么结果……这跟LLM预测下一个token,本质上有多大区别?

也许根本没有本质区别。也许所谓的”理解”、”意识”、”智能”,都只是涌现出来的高级模式,而不是什么神秘的东西。但也可能有本质区别。也许人类的智能有某种LLM永远达不到的特质——比如主观体验、自由意志、创造性……

 **我不知道答案。可能没人知道。** 

## 八、所以,未来会怎样?

> 如果预测下一词就这么强,那是不是规模越大就越聪明? 无限scaling下去能达到AGI?

 **我的判断是:可能,但不够。** 

首先,目前的模型规模可能还远远不够。人脑有860亿个神经元,1000万亿个突触——相当于几百万亿参数的神经网络。而GPT4据传才1.8万亿参数，GPT5的争议就比较大了。而我们可能才用了人脑容量的1%-10%。

继续scaling,可能还会有更多能力出现。但可能需要架构创新。人脑不是一个均匀的神经网络,而是有功能分区的:海马体负责记忆、前额叶负责规划、小脑负责运动控制…这种模块化的设计可能是必要的。就像现在的AI系统开始加入外部记忆(RAG)、工具调用(Function Calling)、多Agent协作等等，这些都是在模拟大脑的模块化。

还有一个很多人忽略的点: **真正的智能可能需要身体。** 

这是认知科学的共识。很多高级认知能力像空间推理、因果理解、社交互动这些都是从与物理世界的交互中涌现的。一个从来没碰过物体的AI,可能永远理解不了”重”、”轻”、”硬”、”软”这些概念的真正含义。

所以机器人可能不是AI的应用,而是 **通往AGI的必经之路** 。

LLM确实学到了一些东西,但这个”东西”可能和人类的智能有本质区别。它是一种 **功能性的近似** ,而不是机制上的复制。飞机不是通过模仿鸟的翅膀来飞的,但它确实飞起来了。LLM可能不是通过人类的方式来”思考”,但它确实能解决一些需要思考的问题。

这够吗?看你的需求。

如果你只是想要一个能帮你写代码、翻译文档、回答问题的工具,那够了。有时候我觉得,纠结”LLM是否真的理解”就像纠结”计算器是否真的懂数学”。重要的不是它怎么做到的,而是它确实做到了。

 **所以我上面写的那些”解释”,更像是一些有启发性的假说,而不是盖棺定论的真理。** 

这个领域才发展了几年,现在下结论还太早。也许再过5年、10年,我们回头看,会发现现在的很多争论都是在盲人摸象。也许那时候我们会发现,LLM根本不是通往AGI的路径,只是个过渡产物;也许我们会发现,原来scaling真的能解决一切,GPT-10已经比人类聪明了。

 **谁知道呢?**
