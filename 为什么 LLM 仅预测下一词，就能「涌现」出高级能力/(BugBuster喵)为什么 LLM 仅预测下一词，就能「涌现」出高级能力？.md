预测下一个词，听起来是一个简单的任务，但为了完美地完成这个任务，模型被迫学会了理解整个世界。

想象一下，我把互联网上所有的书、代码、对话记录、论文全部喂给一个模型。然后我遮住最后一个词，让它猜。

刚开始，它确实是在瞎猜，大概率是统计学上的高频词。比如我说“今天天气”，它后面接“不错”或者“很好”的概率很大。这时候它确实就是个鹦鹉。

但你有没有想过，当语料变得足够复杂，复杂到涉及逻辑推理、涉及代码执行、涉及情感博弈的时候，单纯靠统计概率还管用吗？

<mark>这就是我们要聊的第一个关键点：压缩即智能。</mark>

OpenAI 的联合创始人 Ilya Sutskever 一直在强调这个观点。我也是在反复折腾模型收敛的时候才真正悟透这句话。

<mark>为了把下一个词预测准，模型必须把前面所有的信息进行极致的压缩</mark>。注意，这里的压缩不是像 WinRAR 那样无损压缩，而是一种有损的、提取特征的压缩。

我给你们举个具体的场景。

<mark>假设有一本侦探小说，前两百页极其详尽地描述了一个复杂的谋杀案，出场人物有三十个，每个人的时间线、动机、不在场证明都错综复杂。</mark>

<mark>到了小说的最后一句话：凶手就是\_\_\_\_。</mark>

现在，我要让 LLM 预测这个横线里的名字。

请问，它如果只是统计前面出现名字的频率，能猜对吗？如果它只是做简单的 n-gram 匹配，能猜对吗？绝对不可能。

<mark>为了填对这个词，模型必须在它的神经网络内部构建出一个完整的案件图谱。它必须理解什么是谋杀，什么是动机，谁撒谎了，谁的时间线对不上。它必须学会推理，必须学会排除法。mark>

如果它学不会这些，它在这个样本上的 Loss（损失函数）就会非常高。梯度下降算法不仅是残酷的，也是极度功利的。为了降低这个 Loss，反向传播会疯狂地修改神经网络的权重，逼迫模型去寻找数据背后的深层规律，而不是表层的统计规律。

在这种极端的压力下，推理能力涌现了。

这不仅仅是记忆，这是对数据生成过程的逆向工程。模型为了预测结果，被迫学会了产生这些数据的底层逻辑。

<mark>这里我强烈推荐大家去读一下 Rich Sutton 写的 The Bitter Lesson。这是一篇神文，虽然不长，但振聋发聩。它讲的核心道理就是，在这个领域，所有试图由人类专家把知识硬编码进去的方法，最后都输给了单纯依赖算力和数据规模的方法。</mark>

资源推荐： 你直接搜 The Bitter Lesson by Rich Sutton，这就是一篇短博文，读完你会对为什么只有暴力美学才能出奇迹有更深的理解。

好，既然说了预测下一个词是被迫理解世界，那为什么以前的模型不行？为什么到了 GPT-3 之后才感觉突然开窍了？

这就涉及到了第二个核心点：Scaling Laws 和相变。

我在做算法优化的这些年，最直观的感受就是，小模型和大模型根本就是两个物种。

当你参数量很少的时候，模型大概率是在死记硬背。它的容量不够，只能记住一些常见的搭配。但是当参数量突破某个临界点（比如几百亿参数），并且数据量也足够大的时候，神奇的事情发生了。

大家在知乎上应该看过那个关于“顿悟”（Grokking）的图表。就是训练集准确率已经很高了，验证集准确率一直趴在地上不动，看起来像是过拟合了。但是你别停，继续烧钱，继续训练，突然在某个时间点，验证集准确率直接拉升。

模型从“记忆”模式切换到了“泛化”模式。

这种现象在物理学里叫相变，就像水烧到了100度突然变成蒸汽。在神经网络里，这意味着模型发现了一套通用的规则，这套规则比死记硬背更节省脑容量，更能降低 Loss。

这个通用的规则，表现出来就是我们看到的逻辑推理、数学计算、甚至是代码生成能力。

说到代码，这里我必须插一句，这是很多做纯 NLP 的人容易忽视的点。

代码数据的加入，对于 LLM 的逻辑涌现起到了决定性的作用。

我之前参与过一个内部模型的微调项目，当时我们发现，只用文本数据训练出来的模型，说话是很溜，但是逻辑容易崩。后来我们在预训练阶段大量加入了 GitHub 的代码数据。

你要知道，预测代码的下一个词，和预测小说的下一个词，难度是完全不一样的。

小说你可以瞎编，逻辑稍微不通也读得下去。但是代码不行。

`def calculate_area(radius): return 3.14 * radius ** ____`

这里必须填 2。填 3 程序就错了。

更复杂的情况，比如一个长达几百行的 Python 脚本，中间定义了类，继承了属性，最后调用一个方法。模型要预测这个方法的返回值。

为了预测对这个 token，模型必须在它的“大脑”里模拟代码解释器的运行过程。它必须得跟踪变量的状态，理解循环的逻辑，搞清楚函数的调用栈。

这哪里是预测单词，这分明就是在脑子里跑虚拟机。

所以，当模型学会了预测代码，它其实就学会了严格的逻辑推演。这种能力迁移到自然语言任务上，就变成了我们看到的思维链（Chain of Thought）能力。

大家如果对这个感兴趣，一定要去看一篇论文：Sparks of Artificial General Intelligence: Early experiments with GPT-4。微软研究院写的。虽然里面有些吹捧的成分，但他们详细测试了模型在没有专门训练的情况下涌现出的能力，尤其是代码和逻辑这块，分析得非常透彻。

资源推荐： 除了那篇论文，我也推荐大家去 YouTube 上看 Andrej Karpathy 的 State of GPT 演讲。Karpathy 是真大神，讲东西深入浅出，把 Pre-training 和 Fine-tuning 的本质讲得特别清楚，而且没有废话。

咱们再深入一点。预测下一个词，其实是在构建一个世界模型。

以前我们做搜索推荐，做的是判别式模型。就是给你一个东西，你告诉我它是 A 还是 B。这很简单。

生成式模型是完全不同的维度。Yann LeCun 虽然经常在推特上怼 LLM，但他提的 World Model 概念其实很有道理。虽然现在的 LLM 是在离散的 token 空间操作，但它内部学到的表征（Representation）是连续的、高维的向量空间。

你可以把这个高维空间想象成一个超级复杂的地图。在这个地图上，“国王”和“王后”的距离向量，约等于“男人”和“女人”的距离向量。

这只是最简单的例子。在千亿参数的模型里，这种几何关系复杂到人类无法想象。

所有的逻辑关系、因果关系、事实知识，都被编码在这个高维流形（Manifold）里了。

预测下一个词，实际上就是在高维空间里做导航。模型根据当前的上下文（起点），计算出在这个高维地图上应该往哪个方向走，才能到达最合理的终点。

这个过程之所以能产生高级能力，是因为人类的语言本身就是人类思维的投影。语言不仅是交流工具，它是思维的载体。如果你能完美地模拟语言的生成过程，你就在一定程度上模拟了人类的思维过程。

这里我要泼一盆冷水，也是很多知乎高赞回答里没提到的。

现在的 LLM 预测下一个词，确实还有致命的缺陷。

它没有接触过物理世界。它的所有经验都来自于文本。

比如，它知道“苹果掉在地上会碎”，这是因为它读过相关的描述。但它没有真正看见过苹果，没有听过苹果落地的声音，没有痛觉。

这就导致了它有时会产生幻觉。因为它追求的是概率上的合理性，而不是事实上的真理性。如果它的训练数据里充满了关于某个错误事实的描述，它就会一本正经地胡说八道。

这是预测下一个词这个范式的局限性。它学到的是相关性，而不是绝对的因果性。

不过，现在的技术演进非常快。我们看到多模态模型的出现，它们不仅看文本，还看视频，听声音。

这就相当于给模型装上了眼睛和耳朵。当预测的任务从“下一个词”变成了“下一帧图像”或者“下一段波形”时，它对物理世界的理解会指数级上升。

这时候，它就不再是仅仅模拟语言了，它是在模拟物理规律。

我这有个真实的调试案例，特别能说明问题。

前段时间我们在调试一个 RAG系统。用户问了一个非常偏门的金融合规问题。模型一开始回答得似是而非，看着很专业，但引用的条款是错的。

这是典型的“概率拟合”带来的副作用。它记住了法律文书的行文风格，记住了专业术语，但没记住具体的数字。

后来我们调整了 Prompt 的策略，强制模型在回答之前，先生成一段思考过程，也就是我们常说的 Chain of Thought。让它先把问题拆解，检索到的内容列出来，自己检查一遍，最后再生成答案。

结果准确率大幅提升。

这说明什么？说明模型内部其实是具备推理能力的，但是直接预测下一个词这种“快思考”（System 1）模式容易让它嘴瓢。通过强制它输出思考过程，我们激活了它的“慢思考”（System 2）能力。

这也反过来证明了，单纯的 Next Token Prediction 训练出来的模型，其潜力远不止直接输出那么简单。它内部蕴含的逻辑深度，需要通过特定的 Prompt 或者推理时计算（Inference-time Compute）来释放。

从行业趋势来看，现在大家都在卷 Long Context（长上下文）。

以前只能看几千字，现在能看几百万字。这意味着什么？这意味着模型可以直接把整本书、整个代码库装进内存里进行预测。

在这种尺度下，预测下一个词的难度又上了一个台阶。它需要跨越巨大的跨度进行指代消解和逻辑关联。这会倒逼模型进化出更强的记忆调度能力和全局规划能力。

我一直在跟团队里的年轻人说，不要看不起“大力出奇迹”。在数据科学领域，有时候简单粗暴的方法加上极致的工程优化，就是比精巧设计的规则要强。

人类的大脑也是在漫长的进化中，为了生存（预测危险、寻找食物）而演化出来的。你也可以说，人类大脑的本质目标就是预测未来。

所以，LLM 仅靠预测下一个词就能涌现智能，这事儿并不荒谬。它符合信息论的原理，符合压缩理论，也符合我们对学习本质的理解。

最后，给想入行或者想深入了解的朋友一点实在的建议。

别光看公众号的爽文，也别只盯着那些花里胡哨的应用层。沉下心来，去看看 Transformer 的原始论文 Attention Is All You Need，虽然有点枯燥，但那是原点。

资源推荐： 还有一本书叫 Deep Learning，就是 Ian Goodfellow 和 Yoshua Bengio 他们写的“花书”。不用全看，把前面关于概率论和后面关于序列建模的部分看了，你的内功会扎实很多。

一定要去动手跑一跑 demo。现在 Hugging Face 那么多开源模型，自己写几行 Python 代码，打印一下 Attention Map，看看模型在预测下一个词的时候，到底在关注前面的哪些词。你看一眼就会明白，它不是在瞎猜，它是在像外科手术一样精准地提取信息。

总结下来，我的观点很明确：

预测下一个词是表象，压缩和表征学习是本质。

这种极简的训练目标，是一个极其高效的过滤器，它过滤掉了噪音，留下了规律。当规律积累得足够多，量变就成了质变，那就是我们看到的智能。

未来会不会有比 Next Token Prediction 更高级的范式？肯定会有。比如 Energy-based Models，或者结合了符号推理的神经系统。但在当下，把这个推进到极致，已经足够让我们看到 AGI 的曙光了。
